# DAKSHORA WORLD 1.0

Static, colorful, mobile-first prototype for the DakshOra Learn • Build • Prove • Solve • Earn vision.

## Files
- index.html - homepage
- styles.css - visual system
- script.js - interactions and prototype AI flow
- about.html, courses.html, contact.html
- logo.svg
- robots.txt, sitemap.xml, vercel.json

## Deploy
Upload/replace these files in the existing GitHub repository connected to Vercel.

## Important
The DakshOra AI interface in this version is a front-end prototype. A secure backend/API is required before connecting a real LLM. Never expose an AI provider secret key in browser JavaScript.
